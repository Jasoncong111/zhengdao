显示用户当前等级、打卡天数、进度条和下一等级预览

3. ClaimSBTFlow - SBT申领流程组件

3步申领流程：确认 → 连接钱包 → 申领成功

  • 步骤1: 确认申领信息（等级、天数、奖励加成）
  • 步骤2: 连接钱包（MetaMask/Phantom/WalletConnect）
  • 步骤3: 申领中（加载动画）
  • 步骤4: 申领成功（显示交易哈希）
  • 错误状态处理和重试

## 💡 主网部署建议

### 方案 A: 使用 Remix IDE 部署（强烈推荐）

**优点**:
- 无需本地网络配置
- 操作简单直观
- 适合快速部署

**步骤**:
1. 访问 https://remix.ethereum.org/
2. 导入 `contracts/ZhengDao.sol`
3. 编译合约
4. 连接 MetaMask（切换到 BSC 主网）
5. 部署合约
6. 记录合约地址

**预计时间**: 10-15 分钟

### 方案 B: 使用 VPN + CLI 部署

**优点**:
- 可复现部署流程
- 便于自动化

**步骤**:
1. 连接 VPN（推荐香港或日本节点）
2. 运行部署脚本:
   ```bash
   npx hardhat run scripts/deploy-bnb-sbt.js --network bnbMainnet
   ```
3. 等待交易确认
4. 记录合约地址

**预计时间**: 5-10 分钟

### 方案 C: 使用第三方部署平台

  ↓

## 🚀 快速启动指南

### 1. 安装依赖
```bash
npm install
```

### 2. 配置环境变量（可选）
```bash
cp .env.local.example .env.local

# 编辑 .env.local，填写DeepSeek API Key
# DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxx
```

### 3. 启动开发服务器
```bash
npm run dev
```

### 4. 访问应用
```
http://localhost:3000
```

### 5. 生成Demo数据（可选）
```bash
# 方法1：在浏览器控制台执行

    walletAddress: '0x1234567890123456789012345678901234567890',
    days: 30
  })
});

# 方法2：直接访问Analytics页面查看效果
# 连接钱包后，如果没有复盘数据，可以手动创建1-2条
```

## ⚠️ 注意事项

### 1. API Key配置
- DeepSeek API Key为可选项
- 未配置时会自动使用Mock数据
- Mock数据不影响核心功能演示

### 2. 测试网配置
- 当前使用BNB Chain Testnet
- 测试币可从水龙头获取
- 不要使用真实资金

### 3. 数据持久化
- 数据存储在浏览器IndexedDB
- 清除浏览器数据会丢失复盘
- 建议定期导出备份

### 4. 兼容性
- 推荐使用Chrome/Edge浏览器
- 需要支持Web3钱包（MetaMask等）
- 移动端支持（PWA）

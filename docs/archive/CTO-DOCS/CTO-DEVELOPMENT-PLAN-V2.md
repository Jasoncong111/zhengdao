#### TASK-01: 人生规划问卷系统

**优先级**: P0 (核心功能)
**预计工时**: 4-6小时
**负责AI**: AI #4 (UI组件开发)

**功能描述**:
用户首次进入APP时显示的人生规划问卷，设置5年人生目标。

**具体需求**:
1. 创建 `/onboarding` 页面路由
2. 设计问卷流程组件：
   - 欢迎页：介绍产品理念
   - 财富目标：收入目标、存款目标、投资目标等选项
   - 健康目标：运动频率、体重管理、睡眠质量等选项
   - 家庭目标：家庭关系、陪伴时间等选项
   - 其他目标：学习成长、社交关系等选项
   - 确认页：汇总展示所有选择
3. 数据持久化到IndexedDB
4. 首次进入检测逻辑（已完成问卷则跳过）

**产出文件**:
- `app/onboarding/page.tsx`
- `components/onboarding/WelcomeStep.tsx`
- `components/onboarding/GoalStep.tsx`
- `components/onboarding/ConfirmStep.tsx`
- `lib/onboarding-service.ts`
- `lib/db-goals.ts`

**验收标准**:
- [ ] 首次进入自动跳转到问卷页面
- [ ] 问卷流程流畅，可前进/后退
- [ ] 数据正确保存到本地数据库
- [ ] 完成后不再显示问卷
- [ ] UI风格与现有水墨风格统一

#### TASK-03: 周期复盘系统

**优先级**: P0 (核心功能)
**预计工时**: 6-8小时
**负责AI**: AI #3 (前端核心开发)

**功能描述**:
基于用户每日输入，提供周期性复盘总结。

**具体需求**:
1. 创建 `/review` 页面路由
2. 四个复盘周期：
   - 7日复盘：近一周数据汇总
   - 30日复盘：近一月数据汇总
   - 半年复盘：近半年数据汇总
   - 年度复盘：全年数据汇总 + 目标对比
3. 数据展示：
   - 打卡天数统计
   - 「是/否」比例饼图/柱状图
   - 每日打卡记录数据量曲线
   - AI生成的周期总结
4. 年度复盘特殊功能：
   - 对比年初设定的目标
   - 分析目标达成度
   - 定位问题月份/时间点
   - 给出改进建议

**产出文件**:
- `app/review/page.tsx`
- `app/review/[period]/page.tsx` (7d, 30d, 6m, 1y)
- `components/review/PeriodSelector.tsx`
- `components/review/StatsSummary.tsx`
- `components/review/YesNoChart.tsx`
- `components/review/AIReviewSummary.tsx`
- `components/review/GoalComparison.tsx`
- `lib/review-service.ts`

**验收标准**:
- [ ] 四个周期复盘页面正常显示
- [ ] 数据统计准确
- [ ] 图表展示正确
- [ ] AI总结功能正常
- [ ] 年度复盘目标对比功能完整

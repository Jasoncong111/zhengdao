## 🚀 快速开始

### 前置要求

- **Node.js**: 18.0.0 或更高版本
- **npm**: 9.0.0 或更高版本
- **Git**: 最新版本
- **钱包**: MetaMask（BNB Chain）或 Phantom（Solana）

### 5分钟快速启动

```bash
# 1. 克隆项目（如果还没有）
git clone <repository-url>
cd 黑客松项目-证道

# 2. 安装依赖
npm install

# 3. 配置环境变量
cp .env.local.example .env.local
# 编辑 .env.local 填入必要的环境变量

# 4. 启动开发服务器
npm run dev

# 5. 打开浏览器
# 访问 http://localhost:3000
```

### 验证安装

```bash
# 检查项目是否正常启动
npm run dev

# 在另一个终端验证测试框架
npm test
```

## 📖 项目概览

### 产品定位

**证道** 是一个基于 BNB Chain 和 Solana 的双链 SBT 成就系统，用户通过"吾日三省吾身"的每日反思来累积修行天数，达到不同等级后可以铸造不可转移的 Soulbound Token (SBT) 作为修行证明。

### 核心特性

- ✅ **双链支持**: BNB Chain 和 Solana
- ✅ **6个等级**: 从见素到抱一的修行境界
- ✅ **SBT系统**: 不可转移的灵魂绑定代币
- ✅ **水墨风格**: 独特的东方美学设计
- ✅ **AI复盘**: 集成 DeepSeek AI 进行智能反思

### 技术栈

**前端**:
- Next.js 15.1 + React 19
- TypeScript 5.3
- TailwindCSS + Framer Motion
- TanStack Query + Dexie

**Web3**:
- BNB Chain: Wagmi v2 + Viem
- Solana: @solana/web3.js + Wallet Adapter
- 智能合约: Solidity 0.8.20 (BNB), Rust (Solana)

**开发工具**:
- Jest + Testing Library
- ESLint + Prettier
- Hardhat (BNB), Anchor (Solana)

## ⚙️ 环境配置

### 环境变量设置

创建 `.env.local` 文件：

```bash
# DeepSeek AI API
NEXT_PUBLIC_DEEPSEEK_API_KEY=your_deepseek_api_key

# BNB Chain (可选)
NEXT_PUBLIC_BNB_CHAIN_ID=97
NEXT_PUBLIC_BNB_RPC_URL=https://data-seed-prebsc-1-s1.binance.org:8545/

# Solana (可选)
NEXT_PUBLIC_SOLANA_RPC_URL=https://api.devnet.solana.com
NEXT_PUBLIC_SOLANA_NETWORK=devnet
```

### 获取 API 密钥

**DeepSeek API**:
1. 访问 https://platform.deepseek.com/
2. 注册账号
3. 创建 API 密钥
4. 复制到 `.env.local`

## ❓ 常见问题

### Q1: 如何切换区块链？

**A**: 使用界面右上角的链切换按钮，或调用 `chain-manager.ts`:

```typescript
import { switchChain } from '@/lib/chain-manager';

// 切换到 BNB Chain
await switchChain('bnb');

// 切换到 Solana
await switchChain('solana');
```

### Q2: 如何获取测试币？

**BNB Chain Testnet**:
1. 访问 https://testnet.bnbchain.org/faucet-smart
2. 输入钱包地址
3. 领取测试 BNB

**Solana Devnet**:
1. 访问 https://faucet.solana.com/
2. 输入钱包地址
3. 领取测试 SOL

### Q3: 如何铸造 SBT？

**步骤**:
1. 连接钱包（MetaMask 或 Phantom）
2. 完成每日反思（3个问题）
3. 达到等级要求（见素→怀仁→立德...）
4. 点击"铸造 SBT"按钮
5. 确认交易
6. 等待交易确认

### Q4: 如何查看已铸造的 SBT？

**方法**:
1. 在主页面点击"我的成就"
2. 查看 SBT 画廊
3. 或在链上浏览器查询：
   - BNB: https://testnet.bscscan.com/
   - Solana: https://explorer.solana.com/

### Q5: AI 复盘功能如何使用？

**步骤**:
1. 点击"每日反思"
2. 回答3个问题：
   - 今天做了什么？
   - 学到了什么？
   - 明天如何改进？
3. 点击"生成 AI 复盘"
4. 等待 AI 分析
5. 查看智能建议

### Q6: 如何重置进度？

**开发环境**:
```bash
# 清除本地数据
npm run reset-data

# 或在浏览器
# 开发者工具 → 应用 → 存储空间 → IndexedDB → 删除
```

## 🔧 故障排查

### 问题 1: 依赖安装失败

**症状**: `npm install` 报错

**解决方案**:
```bash
# 清除缓存
npm cache clean --force

# 删除 node_modules
rm -rf node_modules package-lock.json

# 重新安装
npm install
```

### 问题 2: 钱包连接失败

**症状**: 无法连接 MetaMask 或 Phantom

**解决方案**:
1. 确保钱包已安装并解锁
2. 检查网络是否正确（测试网）
3. 刷新页面并重试
4. 或切换钱包账户

### 问题 3: 交易失败

**症状**: SBT 铸造交易失败

**可能原因**:
- Gas 费不足
- 网络拥堵
- 合约未部署

**解决方案**:
1. 检查测试币余额
2. 增加 Gas 费用
3. 稍后重试
4. 查看交易失败原因

### 问题 4: AI 复盘无响应

**症状**: 点击生成复盘后无反应

**解决方案**:
1. 检查 API 密钥是否正确
2. 检查网络连接
3. 查看 API 配额是否用完
4. 查看浏览器控制台错误

### 问题 5: 测试失败

**症状**: `npm test` 报错

**解决方案**:
```bash
# 查看详细错误
npm test -- --verbose

# 清除 Jest 缓存
npm test -- --clearCache

# 单独运行失败的测试
npm test <test-file-name>
```

### 问题 6: 构建失败

**症状**: `npm run build` 报错

**解决方案**:
```bash
# 检查 TypeScript 错误
npm run type-check

# 修复 lint 错误
npm run lint -- --fix

# 清除 .next 缓存
rm -rf .next

# 重新构建
npm run build
```

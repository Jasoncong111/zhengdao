## 📋 任务详细说明

### TASK-MAINNET-01: BSC 主网部署 (AI #1)

**优先级**: P0 (阻塞)
**预计时间**: 1-2 小时

#### 执行要求

1.  **修改部署配置**
    *   将 `hardhat.config.ts` 中的网络从 `bnbTestnet` 切换到 `bnbMainnet`
    *   确认主网 RPC: `https://bsc-dataseed.binance.org/`
    *   确认 Chain ID: `56`

2.  **准备部署账户**
    *   确认 `.env.local` 中的 `PRIVATE_KEY` 对应的账户有足够的 BNB（至少 0.1 BNB）
    *   **安全提示**: 使用专用的部署账户，不要使用个人主账户

3.  **执行部署**
    ```bash
    npx hardhat run scripts/deploy-bnb-sbt.js --network bnbMainnet
    ```

4.  **记录合约地址**
    *   将部署后的合约地址记录到 `MAINNET-DEPLOYMENT-INFO.md`
    *   更新 `.env.local` 中的 `NEXT_PUBLIC_ZHENGDAO_SBT_ADDRESS`

5.  **验证合约（可选但推荐）**
    ```bash
    npx hardhat verify --network bnbMainnet <合约地址> "ZhengDao Soulbound Token" "ZDSBT" "https://your-domain.com/api/sbt-metadata/"
    ```

#### 验收标准
*   ✅ 合约成功部署到 BSC 主网
*   ✅ 可在 BscScan 主网上查看合约
*   ✅ 合约地址已记录并更新到环境变量

## ⚠️ 风险和注意事项

### 主网部署风险

1.  **不可逆性**: 主网部署后无法撤回，必须确保合约代码正确
2.  **资金安全**: 使用专用部署账户，不要暴露私钥
3.  **Gas 费用**: 主网 Gas 费用较高，确保账户有足够余额

### 应急预案

1.  **合约部署失败**: 检查账户余额和网络配置，重新部署
2.  **前端集成失败**: 回滚到测试网配置，排查问题后再切换
3.  **功能异常**: 立即暂停用户访问，排查并修复问题
